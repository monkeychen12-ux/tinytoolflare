# TinyToolFlare

![TinyToolFlare logo](assets/logo.png)

TinyToolFlare is a free online toolbox for everyday browser tasks.

Website: [tinytoolflare.com](https://www.tinytoolflare.com)

Use it to compress images, convert images to PDF, export PDF pages to images, remove photo location metadata, format JSON/XML, generate passwords and UUIDs, calculate BMI, compare unit prices, decode laundry symbols, and more.

## Why TinyToolFlare

- Free online tools for common daily tasks
- No installation required
- Simple browser-first workflows
- Focused pages that are easy to bookmark and share
- English and Chinese pages with canonical and alternate language URLs


Then open `http://localhost:3000`.
